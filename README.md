# TikTok Social Boost — GitHub Pages

Application statique compatible avec GitHub Pages. Les statistiques sont saisies manuellement et conservées localement dans le navigateur.

## Publication
Téléverse tous les fichiers et le dossier `icons` à la racine du dépôt. Puis dans Settings → Pages, choisis Deploy from a branch, `main`, `/ (root)`, puis Save.

Aucun mot de passe TikTok n'est demandé. Ce prototype n'automatise pas les likes, abonnements ou commentaires. Les données restent sur cet appareil et peuvent être perdues si les données du navigateur sont effacées.
